# ExoKomodo

ExoKomodo is the AI assistant integrated with the AutoButler project via [OpenClaw](https://openclaw.ai).

## What it does

- Monitors GitHub for issues and pull requests
- Can open PRs, triage issues, and run automated tasks
- Lives in Discord and responds to mentions
- Has access to the repo via the `gh` CLI as `exokomodo-bot`

## This file

This document was created as a demonstration that ExoKomodo has working GitHub access and can open pull requests autonomously.

If you're reading this in a PR — it worked. 🎉
